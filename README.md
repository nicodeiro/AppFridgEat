# FridgEat

App iPhone anti-gaspillage : **ton frigo te dit ce qu'il contient, ce qui va périmer et quoi cuisiner ce soir.**

Sa mascotte, FridgEat, est un frigo avec des yeux. C'est l'écran d'accueil de l'app, et son regard change selon ce qu'il contient.

## État du projet

Le projet repart de zéro. Les décisions (idée, cible, première version, modèle économique, choix techniques, étapes) sont dans [docs/produit.md](docs/produit.md).

Prochaine étape : choisir une direction visuelle, puis construire la mascotte animée et l'écran d'accueil.
